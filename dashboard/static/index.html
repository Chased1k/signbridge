Tech Debt & Future Work

LOW
TD-001: 31 missing ASLLVD videos
Corrupted/missing source files. 93.6% coverage sufficient for POC. Fix: re-download or use synonym glosses.
LOW
TD-004: Deictic signs are placeholder color videos
20 pronoun/common words (YOU, HE, SHE, WE, etc.) generated as solid-color placeholders. Need proper pose extraction from sample videos or hand-drawn keypoints. Functional for POC pipeline flow.
MED
TD-002: MediaPipe vs RTMPose
MediaPipe (75 keypoints) used instead of RTMPose (133). Faster on CPU but may miss fine hand shapes. Compare after POC.
LOW
TD-003: DO GPU whitelisting
DigitalOcean GPU droplets blocked via API. Open support ticket when GPU needed.
MED
FW-006: Fine-tuned translation model
General LLM rephrasing works (~71% hit rate). A fine-tuned ASL gloss model would handle classifiers, spatial refs, non-manual markers better.
LOW
FW-007: Database & pipeline scale-up
If POC succeeds: RTMPose on dedicated GPU, vector search for semantic gloss matching, caching layer, queue system.
